# PI-AGENTS.md 规范

`PI-AGENTS.md` 是 Pi Workbench 自己的工作区指令文件。它与 Codex、Claude 等工具使用的 `AGENTS.md` / `CLAUDE.md` 分开，Pi Workbench 不会把那些文件当作自己的项目指令读取。

## 发现与优先级

- 只识别精确文件名 `PI-AGENTS.md`，编码为 UTF-8。
- 从工作区根目录沿当前活动目录的祖先链查找，按根目录到当前目录的顺序拼接；兄弟目录和工作区外文件不参与。
- 不读取用户主目录中的全局指令文件。当前 Web 工作区活动目录为根目录，因此首版通常只会加载工作区根部文件。
- 内建系统提示词定义 Agent 身份、能力边界和工具使用规则；`PI-AGENTS.md` 补充项目约定。项目文件不能扩大已授权工具能力、推翻安全边界，或要求对无关请求读取工作区。
- 用户当前请求决定本轮任务。项目指令只约束如何完成该任务，不能把问候、闲聊或一般知识问题转成仓库检查任务。

## 内容约定

使用普通 Markdown，优先写稳定、可执行的规则：项目结构、常用命令、代码约定、验证要求和领域术语。把具体任务步骤留给用户请求；不要把教程流程、每轮固定扫描或宽泛的“先检查整个项目”写成默认要求。

示例：

```markdown
# Pi 项目指令

- 回答一般问题时不访问工作区；用户要求依据项目内容回答时，只检查相关文件。
- 代码使用 Python 3.11+、类型标注和 Ruff 格式。
- 改动后运行与改动范围匹配的 pytest。
- 只使用本轮服务端注册的工具；文件修改和命令执行遵循服务端审批策略，仅在工具结果确认成功后报告已完成。
```

新会话在模型调用时读取指令。修改文件后，后续模型调用会重新发现并加载当前文件；当前实现不提供热重载通知或 UI 编辑器。
