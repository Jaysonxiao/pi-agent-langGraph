## B. 进入点：M8.1 配置与凭据边界

### 设计映射

问题：真实服务需要 model、endpoint 和凭据。若在模型节点里临时读取环境变量、构造客户端，配置错误会延迟到运行期间，错误正文还可能污染事件和 checkpoint。

Pi 固定基线的 `packages/agent/src/agent-loop.ts:streamAssistantResponse()` 在模型流启动前解析 API key，并传给 `streamFunction`。本项目保留运行期依赖注入的思想，先通过纯配置解析函数确定配置，再由 M8.2 工厂构造模型。首版不实现 OAuth 或过期 token 刷新。源码与框架核验说明见 PLAN 的 M8 B 节。

配置解析位于图外，不需要新增 LangGraph 节点或 reducer。现有 `RunContext.model` 接收构造完成的模型；`model_node()` 继续读取消息并调用模型。这样配置校验和图状态更新各自可测试。

### 当前练习与脚手架

核心函数规格：

```python
resolve_model_config(
    options: ModelOptions,
    environ: Mapping[str, str],
) -> ModelConfig
```

- 目标文件：[config.py](../../src/pi_agent/models/config.py)，核心函数 `resolve_model_config()` 已完成。
- 测试文件：[test_config.py](../../tests/models/test_config.py)，57 个参数展开后的测试用例。
- 助手已提供：ModelOptions、ModelConfig、ModelConfigError、SecretStr 容器、public_dict 诊断投影、合成环境 fixture 和测试；这些类型与辅助代码支撑一个核心练习。
- 学习者负责：配置来源优先级、解析及提前校验这一项核心实现，已完成并通过目标测试。
- 输入输出：显式选项与只读环境映射输入；返回经校验配置，失败抛出不带敏感输入的字段级错误。
- 约束：显式值优先于环境变量；fake 无需 key；真实 provider 缺少 key/model 或 URL 非法时失败；拒绝 URL 凭据；时间值为有限正数，max_attempts 为正整数；不读写实际环境、不构造 SDK 客户端、不发网络请求。
- 安全边界：密钥封装在运行期 secret 容器中，公开表示不得含明文；后续不得将配置对象或凭据放入 checkpoint。

配置契约（本切片固定）：

| ModelOptions 字段 | 对应环境变量 | 缺省值 |
|---|---|---|
| provider | PI_AGENT_PROVIDER | fake |
| model | PI_AGENT_MODEL | compatible 必填 |
| base_url | PI_AGENT_BASE_URL | compatible 必填 |
| api_key_env | PI_AGENT_API_KEY_ENV | PI_AGENT_API_KEY（变量名） |
| timeout_seconds | PI_AGENT_TIMEOUT_SECONDS | 30.0 |
| max_attempts | PI_AGENT_MAX_ATTEMPTS | 3（包含首次请求） |
| run_timeout_seconds | PI_AGENT_RUN_TIMEOUT_SECONDS | 120.0 |

优先级逐字段判断：显式值非 None → 环境映射含该键 → 缺省值。被选中的空白/非法值应失败，不得回退到低优先级来源。provider 仅接受 fake/compatible；model 去除首尾空白后必须非空。fake 忽略 model、base_url 和凭据配置，返回这三个字段为 None，但仍校验三个数值预算。

compatible 的 URL 必须为 HTTP(S)、含 host、端口合法，禁止空白字符、用户名/密码、query 与 fragment；保留原始路径和末尾斜线，不自动拼接 `/v1`。可使用标准库 `urllib.parse.urlsplit`，注意解析成功本身不等于 URL 合法。

key 变量名必须匹配 `[A-Za-z_][A-Za-z0-9_]*`。从该名称指定的 environ 值读取 key，缺失或全空白时报 api_key 错误，不回退其他变量；非空 key 原值封装为 SecretStr。key 不作为显式参数传入。时间值须有限且大于零；attempts 须为正整数；显式 bool 无效。整轮时间可以小于单次超时，实际裁定留给后续 runtime。

失败统一使用 `ModelConfigError`，其 `.field` 为失败字段名；构造器只生成安全固定消息。转换解析异常时用 `raise ModelConfigError(...) from None`，避免 traceback 显示被拒绝的原值。ModelConfig 是解析结果 DTO，不负责自行验证；`public_dict()` 是本切片支持的诊断投影，不要用通用 dataclass 序列化代替它。

先读 fixture 和默认 fake 测试，再实现来源选择、数值校验、compatible 必填项和秘密封装。输入映射为只读 Mapping，所有 fixture 均为合成数据。`.env.example` 仅说明变量名，当前 CLI 尚未接入这些选项，也不自动加载该文件。

此前脚手架交付遗漏已补齐；本切片核心函数现已完成。

## E. M8.4 进入点：错误分类与有界重试

当前只推进同步策略，不调用真实 provider。输入是一项模型请求和显式 `RetryPolicy`；输出是成功响应，或达到 attempt/deadline 后的安全失败。瞬时连接/超时/限流可以重试，鉴权、quota、非法参数、协议损坏和取消必须停止；sleep、clock、jitter 均可注入，避免测试真实等待。

- 目标文件：`src/pi_agent/runtime/policy.py`、`src/pi_agent/runtime/retry.py`。

- 核心约束：`max_attempts` 包含首次调用；等待计入 `run_timeout_seconds`；最后一次失败后不再 sleep；不重试工具和整张 graph；异常正文不得泄露密钥。
- 真实网络不在本节点；应使用合成异常、注入 clock/sleep 和本地 fake。
