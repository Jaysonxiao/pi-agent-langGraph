## A. 从整体看本阶段

```text
M1-M6 completed                 M7 in_progress                         M8+ pending
用户输入 + 完整 checkpoint 历史 + workspace rules
                    -> 模型可见上下文 -> model/tool loop -> 完整状态继续持久化
                       ^^^^^^^^^^^^^^^
                            M7 负责
```

当前 `model_node()` 把完整 `state["messages"]` 直接传给模型，因此 workspace 指令、预算和摘要都没有独立边界。M7 要保留完整审计状态，同时按确定顺序派生一次性的模型上下文。LangGraph 官方设计建议 state 保存原始数据、在节点调用模型时按需格式化；本项目不会把渲染后的 prompt 反写成唯一历史。

## B. 当前纵向切片

```text
workspace/
  AGENTS.md                         # 宽规则
  packages/
    AGENTS.md                       # 更具体
    agent/
      AGENTS.md                     # 当前组件规则
      src/main.py                   # active_path
    sibling/AGENTS.md               # 不在祖先链，忽略

active_path
  -> WorkspacePathPolicy.resolve
  -> workspace root 到 active directory 的目录链
  -> 每层检查 AGENTS.md
  -> (root, packages, agent)         # 宽到窄
```

失败路径：活动路径在 workspace 外时沿用 `PathPolicyError(outside_workspace)`；没有任何规则时返回空 tuple。发现阶段不读取内容，因此编码、大小限制和 prompt 注入风险留给后续切片。

## C. Pi 设计与 LangGraph 改写

Pi coding-agent 的 resource loader 在 Agent 核心循环外发现项目资源，`transformContext` 再把持久消息变成模型输入。本项目保留“发现、装配、持久化相互分离”的设计：M7.1 是纯文件定位；后续装配在模型调用前产生临时消息序列；checkpoint 继续保存原始 `AgentState.messages`。

| 问题 | 改写选择 | 原因 |
|---|---|---|
| 规则优先级不可解释 | 根目录到活动目录，宽到窄 | 顺序稳定，窄规则可在后续覆盖宽规则 |
| 活动路径可能越界 | 复用 `WorkspacePathPolicy` | 不在 context 模块复制安全策略 |
| 扫描整个仓库成本与污染 | 只遍历祖先目录链 | 不引入兄弟项目规则 |
| prompt 与审计历史混合 | 本切片只返回 `Path` | 后续按需读取/渲染，不修改 state |

## D. 唯一学习任务

- 目标文件：`src/pi_agent/context/instructions.py`
- 目标签名：`discover_workspace_instruction_files(policy, active_path) -> tuple[Path, ...]`
- 输入：已经初始化的 `WorkspacePathPolicy`；存在的活动文件或目录路径。
- 输出：已 canonicalize 的 `AGENTS.md` 路径 tuple，严格按 workspace 根到活动目录排序。
- 实现要求：
  1. 先用 `policy.resolve(active_path)` 校验并 canonicalize 活动路径。
  2. 活动路径为文件时从 parent 开始；为目录时包含该目录。
  3. 只构造 `policy.root` 到活动目录的祖先链，不使用递归 glob。
  4. 每层仅检查 `INSTRUCTION_FILENAME`；存在时再次通过 policy 解析并要求是普通文件。
  5. 返回 tuple；无规则返回空 tuple。
- 非目标：不读取文件内容；不查用户主目录/global 配置；不创建 `SystemMessage`；不估算 token；不改 graph、state 或 `RunContext`。
- 测试：`tests/context/test_instructions.py`。
- 完成标准：根/中间/当前规则顺序正确，兄弟规则不出现，目录输入包含自身规则，空结果稳定，越界路径保留 `outside_workspace`。
