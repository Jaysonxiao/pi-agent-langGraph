# M1–M8 阶段总结

截至 2026-09-24（Asia/Shanghai）。阶段状态以 [PLAN](../../PLAN.md) 为准；“已归档”表示文档声明的交付范围完成，不能覆盖各阶段仍列出的验收缺口。历史数字是各阶段当时的结果；本轮独立离线复验为 403 passed、4 deselected，mypy 179 files、Ruff lint/format 通过，参见 [审计记录](../reviews/M1-M8-audit.md)。

## 整体链路与模块分界

`用户输入 → M6 checkpoint 恢复 → M7 临时上下文 → M8 模型调用 → M3 工具路由 → M4 受控 I/O/文件审批 → M5 事件展示 → checkpoint`。LangGraph 提供状态/reducer、调度、条件边和 checkpoint；项目代码定义消息/工具协议、安全策略、Provider 适配、资源所有权和 UI。当前这些能力已分别落地，但公开 `pi-agent` 仍由 fake minimal graph 驱动，真实 Provider 只在程序化入口和显式 smoke 下可调用。依据：[CLI app](../../src/pi_agent/cli/app.py)、[Provider runtime](../../src/pi_agent/cli/runtime.py)、[M8](../acceptance/M8.md)。

## M1 — Python 工程骨架

- **目标与完成**：建立 Python 3.11+ 的 `src` 包、uv 锁文件、pytest/mypy/Ruff/CI 质量门禁；`pi_agent.__version__` 来自发行包元数据。依据：[M1 归档](../acceptance/M1.md)、[包入口](../../src/pi_agent/__init__.py)、[pyproject](../../pyproject.toml)。
- **设计与接口**：用包安装后的元数据作为版本来源；M2 在该结构下增加领域模型和图，不必重做构建。交付 `src/pi_agent/`、`tests/`、`uv.lock`、[CI](../../.github/workflows/ci.yml)。
- **验证与遗留**：M1 历史记录 Python 3.11/3.12/3.13 各 1 项测试、静态检查通过；本轮只复验当前解释器与全仓门禁，历史跨版本日志仍待原始 CI 证据核对。M1 不含图或真实模型。依据：[M1](../acceptance/M1.md)、[审计 V02](../reviews/M1-M8-audit.md)。

## M2 — 消息、状态与最小图

- **目标与完成**：将一次 `HumanMessage → model_node → AIMessage → END` 变成可测试的最小 Agent 回合；错误写入结构化状态。依据：[状态](../../src/pi_agent/domain/state.py)、[模型节点](../../src/pi_agent/graph/nodes.py)、[M2 归档](../acceptance/M2.md)。
- **设计与接口**：`AgentState.messages` 用 `add_messages`，节点只返回增量；模型经 `RunContext` 注入，不存入 checkpoint。M3 在助手工具请求后增加工具边。交付 typed state、fake model、图 builder 和测试。
- **验证与遗留**：2026-09-03 技术验证全仓 9 项通过；2026-09-04 用户确认归档。同期仍无工具、持久化、真实 Provider；详细证据见 [M2](../acceptance/M2.md)。

## M3 — Tool Calling 闭环

- **目标与完成**：完成 model→tools→model 循环、Pydantic 参数校验、未知工具/执行异常的 `ToolMessage`、工具批次上限。依据：[registry](../../src/pi_agent/tools/registry.py)、[graph routing](../../src/pi_agent/graph/routing.py)、[M3 归档](../acceptance/M3.md)。
- **设计与接口**：注册表是运行时能力；`tool_call_id` 关联助手请求，结果消息 `id` 使用 `tool-result:` 命名空间；顺序执行保证确定性。M4 后续提供有副作用的真实工具。交付假 `add` 工具、图节点和目标测试。
- **验证与遗留**：2026-09-11 目标 13 passed、当时全仓 22 passed；未验收并行执行、真实 Provider 工具 schema 或副作用幂等。依据：[M3](../acceptance/M3.md)。

## M4 — 安全 Coding Tools 与文件审批

- **目标与完成**：工作区限制的 read/list/search、精确文本 edit/write、受控 argv 命令、输出限制与文件变更 prepare→approval→apply。依据：[路径策略](../../src/pi_agent/security/path_policy.py)、[文件审批图](../../src/pi_agent/graph/file_approval.py)、[应用器](../../src/pi_agent/tools/file_apply.py)、[M4 归档](../acceptance/M4.md)。
- **设计与接口**：模型参数先校验，再检查 canonical path；文件先做无副作用提案，人审恢复后复核磁盘哈希并同目录原子替换。进程函数按 allowlist/cwd/timeout 运行，与文件审批图独立。M5 可投影这些图/工具事件，M6 可为审批提供持久 checkpointer。
- **验证与遗留**：2026-09-16 最终 HITL 集成 3 passed、当时全仓 76 passed；重验 M4 范围 53 passed。未实现高风险命令的人审产品入口，文件审批仍用 `InMemorySaver`，默认 CLI 不挂 Coding Tools；见 [M4](../acceptance/M4.md) 与 [审计 D03](../reviews/M1-M8-audit.md)。

## M5 — 同步事件与 fake CLI

- **目标与完成**：把 LangGraph updates/messages/custom 转为稳定事件与 JSONL/text；fake CLI 支持逐事件 flush、单次终态、SIGINT 协作取消。依据：[事件适配](../../src/pi_agent/events/adapter.py)、[终态过滤](../../src/pi_agent/events/terminal.py)、[CLI](../../src/pi_agent/cli/app.py)、[M5 归档](../acceptance/M5.md)。
- **设计与接口**：核心图与展示解耦；各层明确关闭自己拥有的 iterator。M6 接受图状态做持久化，不解析渲染文本。交付 `pi-agent` console script、render/jsonl 以及测试。
- **验证与遗留**：2026-09-18 先归档已交付；2026-09-21 闭合 R1–R4，M5 范围 47 passed、当时全仓 123 passed。公开运行 CLI 仍是 fake minimal graph；同步迭代取消不能证明异步 Provider/进程中断。依据：[M5](../acceptance/M5.md)。

## M6 — 会话持久化、恢复与分支

- **目标与完成**：SQLite checkpoint 的会话续聊、历史投影、选中状态 fork、应用 metadata 与 `session list`。依据：[session runtime](../../src/pi_agent/sessions/runtime.py)、[history](../../src/pi_agent/sessions/history.py)、[fork](../../src/pi_agent/sessions/fork.py)、[M6 归档](../acceptance/M6.md)。
- **设计与接口**：`session_id → thread_id`；checkpointer 保存图状态，独立表保存应用元数据；普通下一轮输入区别于 `Command(resume)`。fork 用 `update_state` 建立新 thread，不复制完整祖先 checkpoint/writes。M7 读取完整消息并在调用模型前派生上下文。
- **验证与遗留**：2026-09-21 归档复验全仓 158 passed；跨连接恢复、暂停门禁、fork 期间不执行模型、migration 中间态、损坏 SQLite 有测试。不能据此证明任意崩溃重放的外部副作用恰好一次；checkpoint/metadata 非原子事务。依据：[M6](../acceptance/M6.md)、[审计 D04](../reviews/M1-M8-audit.md)。

## M7 — 上下文装配与长对话压缩

- **目标与完成**：按 global→workspace root→leaf 加载规则、模板/预算、完整历史压缩计划、最近 turn/工具事实保护、同步摘要和诊断入口。依据：[上下文](../../src/pi_agent/context/runtime.py)、[摘要](../../src/pi_agent/context/summarizer.py)、[M7 归档](../acceptance/M7.md)。
- **设计与接口**：持久 history 与本轮模型输入分离；摘要是模型节点前的临时准备阶段，失败时主模型不调用；SQLite 记录仍保留原消息。M8 可替换为 async summarizer 和真实 Provider。交付 `context/`、`pi-agent context inspect`、组合与恢复测试。
- **验证与遗留**：2026-09-22 归档复验全仓 217 passed、M7 范围 56 passed；估算 token 不是精确计费，真实摘要质量/容量未测。依据：[M7](../acceptance/M7.md)。

## M8 — 模型适配、重试、取消与容错

- **目标与完成**：配置/密钥边界、同步/异步 Provider 端口、`httpx` 兼容接口、工具 schema 与协议解析、重试/取消组件、SSE、usage、异步 SQLite、Provider session 和 summary。按用户指示于 2026-09-23 归档已交付代码与离线范围。依据：[模型](../../src/pi_agent/models/http_client.py)、[异步图](../../src/pi_agent/graph/builder.py)、[M8 归档](../acceptance/M8.md)。
- **设计与接口**：模型和凭据由运行时注入；消息状态只存可序列化事实；SSE 只在完整结束后聚合；摘要只派生本轮上下文。可选 live 测试需要显式 `PI_AGENT_LIVE=1`。交付 `models/`、`runtime/`、async graph/session、stream/usage 适配器和离线合约测试。
- **验证与遗留**：2026-09-23 全仓 403 passed、4 live skipped，mypy/Ruff/format 通过；2026-09-24 离线复验 403 passed、4 deselected。用户报告普通回复 live 1 passed；新 streaming、续聊、摘要真实调用未运行。HTTP 端未发送工具 schema，Provider session 仍是最小图；重试/取消组件未接入完整 Provider 请求链，异步进程退出码和 POSIX 树终止存在断点。M9 前需处理 [P0 清单](../follow-ups/M1-M8.md)。依据：[M8](../acceptance/M8.md)、[审计 D06–D09](../reviews/M1-M8-audit.md)。

## M1–M8 总体进展

M1–M7 构成可教学验证的工程、图、工具、安全、事件、会话、上下文链；M8 交付真实 Provider 所需的大部分适配与异步部件。当前“组件已实现”和“公开命令能够完整驱动真实 Coding Agent”仍有距离。后续先按 [F01–F04](../follow-ups/M1-M8.md) 补主链路和安全边界，再执行显式真实服务验收，然后进入 M9 的 tracing/hooks/evals。Git 当前只有两条覆盖 M1–M7 的回溯/阶段提交，M8 工作树尚未形成提交；是否提交不影响本次文档归档结论。
