# M10 归档 — 远程协议与客户端/服务端

- **状态**：`completed`，已交付的离线本机范围归档。M10.1–M10.8 均已完成各自计划验证。
- **日期**：2026-09-24 启动；2026-09-28 完成切片、用户条件授权、归档审查与复验并归档。实现、验收授权和归档是不同动作，不据此推断相同的执行时间。
- **验收口径**：单服务进程、单信任主体、loopback TCP、环境 token、严格 JSON v1、服务端固定 workspace/database/model、只读 read/list/search、fake 模型的可重复进程链路。真实 compatible 模型、外网与多进程协调不在本次离线验收范围。

## 归档结论

客户端经认证和版本握手创建会话，prompt 进入已有 LangGraph 异步只读工具图，服务端把结果写入 SQLite 并返回权威快照。服务端退出、重启后，同一 session 可查询旧历史并继续发送 prompt。M10.8 的公开入口和此前各协议/运行切片已接成同一链路；归档审查补齐已完成 run 与取消相遇时的结果语义、真实服务端进程日志的脱敏断言，以及 TCP 关闭超时必须显式失败的契约。计划门禁全部通过，M10 已交付范围予以归档。

## 验收要求与证据

| 原验收要求 | 证据与结论 |
|---|---|
| 畸形/超大帧拒绝，认证在业务之前 | `test_framing.py` 的拆帧、上限、EOF/失败终态；`test_codec.py` 的严格 JSON/方向/大小；`test_auth.py` 和 `test_tcp_transport.py` 的错误凭据、超时、同包 hello。 |
| 并发请求关联，断线结果明确 | `test_protocol.py` 覆盖握手门禁、未知版本、重复 ID、乱序、容量、断线清理；`test_requests.py` 覆盖 client pending、timeout/outcome unknown、代次与重复响应。 |
| 单 session 所有权、取消/完成竞态与恢复 | `test_sessions.py`、`test_cancellation.py` 覆盖 busy、run ID、join、清理超时、partial checkpoint；完成 task 尚未释放时取消返回 `not_found`，不把完成改报取消。 |
| 权威快照与持久续聊 | `test_snapshots.py` 白名单和展示预算；`test_runtime.py`、`test_app.py` 的 fake read、SQLite reopen 和同 session 续聊；snapshot 查询不启动旧轮次。 |
| memory/TCP 与公开进程一致 | `test_conformance.py` 对同一 create/prompt/snapshot 跑 memory 和 localhost TCP；`test_subprocess_smoke.py` 用独立 server/client 进程读合成文件、关闭重启、复用数据库与 session。 |
| 慢消费者、关闭与资源回收 | `test_tcp_transport.py` 的发送 deadline/预算与幂等关闭；handler 超过关闭期限时 `TcpByteServer.close()` 抛 `TimeoutError`，不报告成功；`test_protocol.py` 的断线 owned-run 清理；`test_app.py` 的模型资源关闭一次；子进程 smoke 要求 server 在信号后限时退出。 |
| 日志不含凭据/正文，既有 CLI/hook 不回退 | 子进程 smoke 断言客户端输出无合成 token，服务端 stdout/stderr 无 token、prompt 或文件正文；全仓非 live 回归及 fake JSONL/eval smoke 通过。 |
