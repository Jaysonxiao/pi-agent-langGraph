## 目标与范围

将一条用户消息走过 `HumanMessage → AgentState → model_node → AIMessage → END`，使最小执行与失败可观察。工具、持久化、真实 Provider 和应用级流事件属于后续里程碑。Pi 的模型循环设计映射依据为 [PLAN 的固定上游基线](../../PLAN.md)；本轮没有重新取得完整上游源码。

## 设计、接口与交付

[AgentState](../../src/pi_agent/domain/state.py) 将累积消息交给 `add_messages`；[节点](../../src/pi_agent/graph/nodes.py) 读取完整 state，但仅返回新助手消息或错误增量；[RunContext](../../src/pi_agent/graph/context.py) 注入模型；[builder](../../src/pi_agent/graph/builder.py) 与 [routing](../../src/pi_agent/graph/routing.py) 控制结束。这样既不重复加入输入，也不会把模型客户端放入可持久状态。交付 typed state、fake model、最小图与 [目标测试](../../tests/graph/test_minimal_graph.py)。
