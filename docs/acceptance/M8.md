## 关键技术决策与保留的限制

- 只有完整 SSE 消息（收到 `[DONE]`）才提交最终回复/usage；EOF 被视为断流。第二轮工具请求需回传 assistant `tool_calls`，避免孤立 `ToolMessage`。参考 [HTTP client](../../src/pi_agent/models/http_client.py) 与 [provider tool-loop 测试](../../tests/integration/test_async_provider_tool_loop.py)。
- 摘要派生临时模型上下文，不覆写 durable history；节点主动取消在 LangGraph 边界可能以包裹 `CancelledError` 的异常呈现。参考 [async 节点](../../src/pi_agent/graph/async_nodes.py) 与 [异步摘要集成测试](../../tests/integration/test_async_summary_context.py)。
- API key 仅通过配置解析进入运行时；`.env` 不自动加载，live 测试必须显式 `uv run --env-file .env` 且设置 `PI_AGENT_LIVE=1`。本次没有读取或记录密钥内容。
- SDK 内层重试应关闭，重试策略归运行时单一所有者；目前这是组件/设计边界，不是当前 provider CLI 已实现的端到端保证。
