## 目标与范围

使同一 `session_id` 对应稳定 `thread_id`，跨 SQLite 重开继续会话，查询历史，从已完成 checkpoint 创建独立状态分支；应用 metadata 与 LangGraph checkpoint 保持分层。生产多租户存储、完整祖先历史复制与默认 fake run CLI 自动持久化不在已验收范围。

## 设计、接口与交付

[会话入口](../../src/pi_agent/sessions/runtime.py) 将新输入作为 graph input 交给 reducer，不手工拼接历史；若 checkpoint 暂停，拒绝普通新一轮，`Command(resume)` 保持独立语义。[历史投影](../../src/pi_agent/sessions/history.py) 将框架 snapshot 转成稳定 DTO；[fork](../../src/pi_agent/sessions/fork.py) 用 `update_state` 从选中完成状态建立 target，不调用模型，也不复制完整 source checkpoint/writes 链。[metadata](../../src/pi_agent/sessions/metadata.py) 有独立 schema/migration，`pi-agent session list` 只输出目录 JSONL。交付 `sessions/`、[续聊测试](../../tests/integration/test_resume.py)、[fork 测试](../../tests/integration/test_fork.py) 及 CLI 测试。
