## 目标与实际范围

为 M3 的工具循环提供受工作区约束的 read/list/search、精确 edit/write、结构化 argv 进程、输出预算、超时，以及 **文件变更** prepare→人工审批→版本复核→原子 apply。M4 原计划还写“高风险命令人审”，当前源码未把命令接到审批图；此验收项不因归档消失。容器隔离、任意 shell 和网络工具不在本阶段范围。依据：[PLAN](../../PLAN.md)、[审计 D03](../reviews/M1-M8-audit.md)。

## 设计、接口与交付

- [路径策略](../../src/pi_agent/security/path_policy.py) 在 I/O 前解析 canonical path 并拒绝越界或 symlink 跳转；[只读工具](../../src/pi_agent/tools/read_only.py) 负责读取/浏览/搜索及输出预算。
- [变更规划](../../src/pi_agent/tools/file_mutation.py) 先产生无副作用提案；[审批图](../../src/pi_agent/graph/file_approval.py) 仅保存、暂停与恢复文件提案；[apply](../../src/pi_agent/tools/file_apply.py) 在批准后复核哈希、同目录 fsync + replace。
- [受控进程](../../src/pi_agent/tools/process.py) 要求 allowlist、结构化 argv、无 shell、cwd 和 timeout。函数本身只检查 cwd 是目录；调用方负责 workspace 授权。该进程能力与文件审批没有同一图级产品入口。
- 文件审批测试用 `InMemorySaver`；M6 后提供 SQLite 会话组件，但本阶段图未自动迁移为持久审批工作流。交付 [HITL 测试](../../tests/integration/test_hitl.py)、[路径测试](../../tests/security/test_path_policy.py) 和工具测试。
